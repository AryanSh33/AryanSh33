> *Hybrid Vision Transformer + CNN · 99.33% Accuracy · 0.9997 ROC-AUC*

Built a dual-stream forensic pipeline where a **ViT-Base/16** acts as a wide-angle lens for global structural inconsistencies, and **ResNet50** acts as a microscope for texture artifacts. The magic? A **bidirectional cross-attention fusion block** lets each stream actively refine the other — trained on 330,000+ images across GANs, diffusion models, and face-swap datasets.

`PyTorch` `timm` `MTCNN` `Streamlit` `AdamW` `RTX 4090`

`Python` `PyTorch` `GNNs` `LLMs` `Cybersecurity`
